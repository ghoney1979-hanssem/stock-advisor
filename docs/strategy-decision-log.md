# 전략별 의사결정 로그 (아카이브)

2026-09-15, CLAUDE.md가 Claude Code의 150k자 상한(당시 201.7k자)을 넘어 이 섹션(전체의 약 절반)을 그대로 옮겼다. 내용은 원본에서 한 글자도 바뀌지 않았다 — **위치만 이동**이며, 매일-분석(`daily-analysis` 스킬)·전략 코드 변경 시 참고할 "왜 지금 이 값인가"의 근거가 전부 여기 있다.

이 문서는 A~P 전략별 도입·수정·폐기 이력, feature 마이닝·대조군 분석·게이트 정책 실험, 백테스트(F-Score·멀티데이·선정축·가치축) 기록을 시간순으로 담은 **실험 일지**다. "지금 시스템이 어떻게 동작하는가"(아키텍처·현재 설정값 요약)는 `CLAUDE.md`의 "실전 매매 안전장치"·"시장 국면 엔진" 절에 남아 있다 — 특히 **현재 LIVE 화이트리스트**는 CLAUDE.md의 `TRADING_LIVE_STRATEGIES` 항목을 볼 것(이 문서 안의 "현행" 서술은 작성 시점 기준이라 최신이 아닐 수 있다).

⚠️ 새로 배포하거나 전략을 바꿀 때 이 문서에 이어서 기록할 것 — CLAUDE.md 본문에 다시 합치지 말고 이 파일에 추가한다(다시 150k를 넘기지 않기 위함).

### 다전략 섀도우 백테스트 (`strategy/` + `StrategyReportService`)
- 5개 전략 `TradingStrategy` 빈, 각자 **`scope()`**: `MOMENTUM_A`=**DISCLOSURE**(공시가 촉매), `VOLUME_LEADING_B`·`MEAN_REVERSION_C`·`INDEX_RELATIVE_D`·`BREAKOUT_E`=**MARKET_SCAN**(공시 무관, 전 종목 스캔). 공통 평가는 `StrategyEvaluator.evaluateStock`(종목당 REQUIRES_NEW): 거래량급증 게이트 → 매도 제외 → scope 필터 전략 평가 → (전략·종목·일자) 1회 기록. 전략 빈은 Spring이 자동 주입하므로 새 전략은 `@Component` + `scope()`만으로 파이프라인(control-group·perf-gate·리스크·사이징)에 자동 편입.
  - **A**: `DisclosurePollingService`→`SignalAlertService`→공시 종목에 DISCLOSURE 전략 평가.
  - **B·C**: `WatchlistScanService.scanAll`이 **15분마다 워치리스트 1500종목 전체**에 MARKET_SCAN 전략 평가(공시와 독립). `TradeOutcome.disclosureId`=null. ⚠️ 전 종목 순회라 무거움(스캔당 ~1500 KIS 일봉콜) → 15분 주기 + scheduler pool 분리.
