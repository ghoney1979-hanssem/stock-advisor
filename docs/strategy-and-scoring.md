# 매수 3전략 & 추천점수 산출 방식

> ⚠️ 아래 임계값·가중치·공식은 **검증 안 된 예시 휴리스틱**입니다. DRY_RUN 포워드 표본으로 검증되기 전까지
> 실제 투자 판단 근거로 사용하면 안 됩니다. (성과 게이트가 표본 누적 전까지 LIVE 실주문을 차단합니다.)

---

## 공통 게이트 (3전략 모두 — 각 전략 고유 조건 전에 통과 필수)

`StrategyEvaluator.evaluateStock` + `MarketSignalService.evaluate`:

1. **연속매매 시간대(09:00~15:20)·당일 거래일**에만 평가 (동시호가·휴장·거래정지 제외)
2. **거래량 급증** — 당일 누적거래량 ≥ (최근 20일 평균 × 2배), 단 **장중 경과시간 비율로 평균을 보정**.
   미급증이면 추천·분봉 호출 없이 즉시 종료 (3전략 공통 대전제)
3. **저가주 제외**(1,000원 미만) · **부실 제외**(관리종목·투자경고·정리매매) ·
   **유동성 필터**(1일 거래대금 ≥ 5억, 추정 왕복 슬리피지 ≤ 1%)
4. **추천 의견이 SELL이면 전 전략 진입 금지** (글로벌 하드 가드)
5. **(전략·종목·일자) 1회** 진입 (중복 방지 dedup)

## A — 공시 모멘텀 확인형 (`MOMENTUM_A`)

- **scope: DISCLOSURE** — 워치리스트 종목에 **신규 공시**가 떴을 때만 평가 (공시가 촉매)
- **진입 조건**: `freshActive` **AND** 추천점수 ≥ 40 (중립 이상)
  - `freshActive` = 거래량 급증 + **당일 상승(≥ +1.5%)** + **분봉 신선·활발**
    - 분봉 신선: 최근 N분 모멘텀 ≥ 0.3% (지금도 상승 중)
    - 분봉 활발: 최근 분당 거래량 ≥ 당일 평균 분당 × 1.5 (지금도 거래 활발)
- **의미**: "공시 호재가 떴고, 지금도 오르며 거래가 붙는 중" → 모멘텀을 **확인하고** 따라붙음.
  "알림 왔는데 이미 식은" 신호를 분봉으로 걸러냄.

## B — 거래량 선행형 (`VOLUME_LEADING_B`)

- **scope: MARKET_SCAN** — 공시 무관, **15분마다 워치리스트 1500종목 전수 스캔**
- **진입 조건**: 거래량 급증 **AND 당일 등락률 0% ~ +1% (횡보, 비대칭 밴드)** **AND** 추천점수 ≥ 40
  - 밴드 하한 `SIGNAL_B_MIN_CHANGE`(기본 0.0), 상한 `SIGNAL_B_MAX_CHANGE`(기본 1.0)
  - **하락 중(등락률 < 0)은 제외** — 거래량 급증 + 하락은 분산(매도)일 수 있어 컷
- **의미**: "거래량은 터졌는데 가격은 아직 횡보" → **돌파 直前 선취** 가설.

## C — 눌림목·역추세 (`MEAN_REVERSION_C`)

- **scope: MARKET_SCAN** — 공시 무관, 15분 전수 스캔
- **진입 조건**: **당일 −3% ~ −12% 하락**(눌림목 범위, 그 이상 폭락 제외)
  **AND** 거래량 급증(투매) **AND** `reboundActive`(분봉 반등 확인) **AND** 추천점수 ≥ **40** (공통과 동일로 완화, 50→40)
  - 하락폭 `SIGNAL_C_MIN_DROP`(기본 3) ~ `SIGNAL_C_MAX_DROP`(기본 12)
  - `reboundActive` = 당일은 하락이어도 **최근 분봉이 반등 중**(모멘텀↑·거래 활발) → "떨어지는 칼날" 회피
  - 점수 게이트 `SIGNAL_C_MIN_SCORE`(기본 40, 50→40 완화)
- **의미**: "우량주가 투매로 눌렸는데 분봉이 반등을 시작" → 역추세 매수.
- **스윙(오버나잇) 청산**: C는 당일 청산이 아니라 **익일(다음 거래일) 종가에 청산**(분석상 C 엣지가 익일 — `trading.swing-strategies`). 따라서 C는 **장마감 초과 청산 진입금지 규칙 면제** → 장중 언제든 진입 가능. 손절·서킷은 장중 적용되나 ⚠️오버나잇 갭 리스크 노출.

### 전략 비교 요약

| | A 모멘텀 | B 거래량선행 | C 역추세 |
|---|---|---|---|
| scope | 공시(DISCLOSURE) | 전수스캔(MARKET_SCAN) | 전수스캔(MARKET_SCAN) |
| 당일 방향 | 상승 ≥ +1.5% | 횡보 0 ~ +1% | 하락 −3 ~ −12% |
| 분봉 확인 | freshActive(상승) | 없음 | reboundActive(반등) |
| 추천점수 게이트 | ≥ 40 | ≥ 40 | ≥ 40 |
| 공통 전제 | 거래량 급증 | 거래량 급증 | 거래량 급증(투매) |

## 추천점수 산출 (`RecommendationService.computeRecommendation`)

**최종점수 = 0.5 × 밸류에이션 점수 + 0.5 × 재무 점수**
(DART 재무 데이터가 없으면 밸류에이션 점수만 사용, reason에 "재무데이터 미반영" 표기)

### ① 밸류에이션 점수 (KIS 시세 PER/PBR, 0~100) — 저평가일수록 높음

**업종 상대평가 우선** (`SectorValuationService`, 기본 on): 종목 업종의 중앙값이 산출돼 있으면
**(종목 PER/PBR ÷ 업종 중앙값) 비율**로 점수화 — `band(ratio, good-ratio=0.8, max-ratio=1.5)`.
업종 평균보다 쌀수록(비율 낮을수록) 고점 → 테크/바이오 같은 업종 고PER 편차를 흡수.
업종 중앙값은 워치리스트 전 종목 시세를 집계(업종별 median, 업종당 ≥5종목), **장전 08:40 배치 + 수동 갱신**
(`POST /admin/refresh-sector-valuation`, 조회 `GET /admin/sector-valuation`). 미산출/표본부족이면 ↓ 절대기준 fallback.

**절대기준 (fallback)** — PER·PBR 각각 0~50점, **"good 이하 만점 → max 이상 바닥(high-floor)"** 으로 완만하게 감점:
- `band(x, good, max)` = good 이하면 50점, max 이상이면 `high-floor`(기본 10), 사이는 선형 보간
- PER 점수 = `band(PER, per-good=10, per-max=40)` (PER ≤ 0 적자면 `loss-score`=15)
- PBR 점수 = `band(PBR, pbr-good=1.0, pbr-max=4.0)` (PBR ≤ 0이면 `loss-score`=15)
- 합산 후 100 상한. anchors는 env `stockadvisor.valuation.*` 로 튜닝.
- ⚠️ **개선 이력**: 구버전 `40 − PBR×20`은 **PBR ≥ 2면 0점**이라 성장주가 BUY 원천 불가였음 →
  `high-floor`로 고평가도 바닥점을 줘서 **우량 성장주도 BUY 도달 가능**하게 수정.
  (여전히 절대기준 휴리스틱 — 업종 상대평가는 후속 과제.)

### ② 재무 점수 (DART 재무, 0~100)
- 매출 성장률: **2%당 1점**, 최대 40점
- 영업이익률: **1%당 2점**, 최대 30점
- 부채 건전성: 부채비율 100% 이하면 만점 30점, 초과분 **%p당 0.15점 감점**

### ③ 등급 분류
- **점수 ≥ 70 → BUY (매수)**
- **점수 ≥ 40 → HOLD (중립)**
- **점수 < 40 → SELL (매도)**

→ 위 전략 게이트의 "추천점수 ≥ 40(A·B) / ≥ 50(C)"이 바로 이 **최종점수** 기준입니다.

## 주의 (검증 상태)
- 가중치(0.5/0.5)·점수 공식·신호 임계값(거래량 2배, A +1.5%, B 0~+1%, C −3~−12%, 점수 40/50 등)은
  **전부 예시값**이며 실데이터 백테스트/포워드 검증 전입니다.
- 현재 DRY_RUN으로 표본을 누적 중이며, (시장,국면)별 net 성과가 검증된 전략만 향후 소액 LIVE로 승격합니다.
